## گام ۱: ساخت ربات در پیام‌رسان بله و دریافت توکن

1. پیام‌رسان **بله** را باز کنید و وارد حساب کاربری خود شوید.
2. در بخش جستجو، شناسه **`@BotFather`** (پدر بازوها در بله) را جستجو کرده و وارد صفحه چت آن شوید.
3. دستور `/newbot` را ارسال کنید.
4. یک نام نمایشی برای ربات بنویسید (مثلاً: `تلگرام ریدر`).
5. یک شناسه انگلیسی که به `bot` ختم شود انتخاب کنید (مثلاً: `my_tg_reader_bot`).
6. ربات‌ساز بله یک **توکن اختصاصی (Bot Token)** به شما تحویل می‌دهد. این رشته را کپی و در جایی امن یادداشت کنید:
   ```text
   مثال توکن: 123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
   ```

## گام ۲: ایجاد مخزن در گیت‌هاب و ارسال کدها

> [!IMPORTANT]
> برای استفاده از سقف رایگان و نامحدود گیت‌هاب اکشنز، نوع مخزن را حتماً **Public** انتخاب کنید. چون کانال‌های تلگرام عمومی هستند، عمومی بودن مخزن هیچ ریسکی ندارد.

1. وارد حساب کاربری [GitHub](https://github.com/) شوید و یک مخزن جدید (New Repository) به نام دلخواه (مثلاً `bale-telegram-viewer`) بسازید.
2. در محیط لوکال خود، دستورات زیر را برای ارسال اولیه کدها اجرا کنید:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for bale telegram viewer"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/bale-telegram-viewer.git
   git push -u origin main
   ```

## گام ۳: تنظیم دسترسی‌های GitHub Actions و فعال‌سازی GitHub Pages

### الف) اعطای دسترسی نوشتن به اکشن‌ها:
برای اینکه اسکریپت بتواند داده‌ها و تصاویر را روی شاخه `gh-pages` مستقر کند:
1. در صفحه مخزن گیت‌هاب خود به تب **Settings** بروید.
2. از منوی سمت چپ روی **Actions** و سپس **General** کلیک کنید.
3. در انتهای صفحه به بخش **Workflow permissions** بروید و گزینه **Read and write permissions** را انتخاب کرده و روی **Save** بزنید.

### ب) اجرای اولین چرخه جمع‌آوری داده:
1. به تب **Actions** در مخزن بروید.
2. از ستون سمت چپ روی ورک‌فلو **Telegram Collector & Deploy** کلیک کنید.
3. دکمه **Run workflow** را بزنید تا اولین اجرا به صورت دستی آغاز شود.
4. پس از ۱ الی ۲ دقیقه، اکشن سبز می‌شود و به طور خودکار شاخه جدیدی به نام **`gh-pages`** در مخزن ایجاد می‌کند.

### ج) فعال‌سازی میزبانی GitHub Pages:
1. مجدداً به تب **Settings** مخزن بروید.
2. از منوی سمت چپ روی بخش **Pages** کلیک کنید.
3. در قسمت **Build and deployment**:
   * گزینه **Source** را روی **Deploy from a branch** بگذارید.
   * در بخش **Branch** شاخه **`gh-pages`** و پوشه **`/(root)`** را انتخاب کرده و دکمه **Save** را بزنید.
4. پس از چند لحظه، آدرس سایت شما در بالای همان صفحه نمایش داده می‌شود:
   ```text
   https://<YOUR_USERNAME>.github.io/bale-telegram-viewer/
   ```
   این آدرس اینترنتی مینی‌اپ شماست!

## گام ۴: اتصال مینی‌اپ به ربات بله (بدون نیاز به سرور)

به لطف متد استاندارد `setChatMenuButton` در بله، نیازی به روشن نگه داشتن هیچ سروری ندارید. با اجرای یک دستور ساده در رایانه خود، دکمه مینی‌اپ برای همیشه در کنار کادر پیام ربات قرار می‌گیرد:

```bash
python bale/setup_bot.py --token "توکن_ربات_شما" --url "https://<YOUR_USERNAME>.github.io/bale-telegram-viewer/"
```

خروجی موفقیت‌آمیز:
```text
[*] در حال ارسال درخواست به https://tapi.bale.ai...
✅ دکمه مینی‌اپ با موفقیت روی ربات تنظیم شد!
🔗 آدرس مینی‌اپ: https://<YOUR_USERNAME>.github.io/bale-telegram-viewer/
🔘 متن دکمه: کانال‌های تلگرام
```

حالا در گوشی همراه خود اپلیکیشن بله را باز کنید، به صفحه ربات بروید و روی دکمه شیشه‌ای منو کلیک کنید تا مینی‌اپ بدون نیاز به فیلترشکن باز شود!

## گام ۵: نحوه افزودن یا تغییر کانال‌های تلگرام

برای اضافه کردن کانال‌های جدید:
1. فایل [`config/channels.json`](file:///d:/Joud%20Files/Bale%20Telegram%20Viewer/config/channels.json) را در مخزن خود باز کنید.
2. شناسه کانال عمومی تلگرام (عبارتی که بعد از `t.me/s/` می‌آید) را به آرایه `channels` اضافه کنید:
   ```json
   {
     "id": "channel_username",
     "title": "عنوان دلخواه شما",
     "enabled": true,
     "description": "توضیح کوتاه کانال"
   }
   ```
3. تغییر را کامیت و پوش کنید (`git push`). گیت‌هاب اکشنز بلافاصله اجرا شده و کانال جدید را اضافه می‌کند. همچنین هر ۱۰ دقیقه یک‌بار به صورت کاملاً خودکار تمام کانال‌ها بروزرسانی می‌شوند.

## نکات عیب‌یابی و پایداری در ایران

1. **نمایش در نسخه وب بله در برابر اپلیکیشن موبایل:**
   * وب‌ویوی موبایل بله (اندروید و iOS) مینی‌اپ را به صورت مستقیم و بدون هیچ‌گونه محدودیت لود می‌کند.
   * اگر نسخه تحت وب بله (`web.bale.ai`) را باز کردید و صفحه سفید ماند، به دلیل سیاست‌های سخت‌گیرانه مرورگر برای `iframe` است. گیت‌هاب پیجز مانع فریم شدن نمی‌شود، اما بهترین و روان‌ترین تجربه کاربری در خود اپلیکیشن بله است.
2. **بروزرسانی داده‌ها و کش مرورگر:**
   * در مینی‌اپ یک متد Anti-Cache با تولید برچسب زمانی (`?t=timestamp`) تعبیه شده است تا همیشه آخرین پست‌ها را دریافت کنید. همچنین با دکمه گردان در بالای مینی‌اپ، کاربر می‌تواند درجا پست‌ها را تازه‌سازی کند.
3. **حجم مخزن و سقف گیت‌هاب:**
   * عکس‌ها به فرمت WebP با کیفیت ۷۵٪ فشرده می‌شوند و روی شاخه `gh-pages` با فلگ `force_orphan: true` مستقر می‌شوند. بنابراین هیچ نسخه‌بندی تاریخی از عکس‌های حذف شده ذخیره نمی‌شود و حجم مخزن همیشه زیر ۳۰ مگابایت می‌ماند.
