# 📡 Bale Telegram Viewer (تلگرام ریدر در بله)

پروژه‌ای متن‌باز، فوق‌العاده سبک، **۱۰۰٪ رایگان و بدون نیاز به سرور (Zero-Server / Serverless)** جهت مشاهده و مطالعه پست‌های کانال‌های عمومی تلگرام از داخل پیام‌رسان **«بله»** بدون نیاز به فیلترشکن.

## 🌟 ویژگی‌های کلیدی

* **بدون نیاز به سرور، هاست یا دیتابیس:** کل پروژه روی زیرساخت رایگان **GitHub Actions** (اسکرپر ابری) و **GitHub Pages** (هاست ایستا) اجرا می‌شود.
* **بدون نیاز به فیلترشکن:** تمامی متن‌ها، تصاویر، صداها و ویدیوها فشرده شده و روی CDN گیت‌هاب قرار می‌گیرند که در داخل ایران بدون فیلترشکن در دسترس است.
* **پخش مستقیم ویدیوهای کوتاه:** ویدیوها، گیف‌ها و ویدیوهای دایره‌ای تلگرام تا سقف ۱۲ مگابایت دانلود شده و مستقیماً در پلیر داخلی HTML5 باز می‌شوند.
* **پخش پیشرفته صوت و پادکست:** فایل‌های صوتی با ابزار `ffmpeg` به فرمت فوق‌سبک MP3 مونو (۴۸kbps) تبدیل می‌شوند (کاهش ۸۰ تا ۹۰ درصدی حجم) تا بدون اشغال حافظه، در چت پخش شوند.
* **اسکرول هوشمند:** به محض باز کردن هر کانال، صفحه به صورت خودکار روی اولین پیام جدید (خوانده‌نشده) متمرکز می‌شود.
* **حذف کانال با لمس طولانی:** با نگه داشتن انگشت روی هر کانال، پنجره تایید حذف ظاهر شده و کانال درجا از لیست شخصی شما حذف می‌گردد.
* **افزودن هوشمند کانال‌های جدید:** هر کاربری می‌تواند با وارد کردن آیدی یا ثبت Issue در گیت‌هاب، کانال‌های جدید را به صورت خودکار به سیستم اضافه کند.
* **پایدارسازی و ادغام مقاوم داده‌ها:** حتی در صورت قطعی موقت تلگرام یا محدودیت نرخ (429)، هیچ کانالی از لیست حذف نمی‌شود و پست‌های پیشین حفظ خواهند شد.

## 🚀 راهنمای راه‌اندازی نسخه شخصی در ۳ دقیقه

هر فرد می‌تواند در کمتر از ۳ دقیقه یک نسخه اختصاصی از این سیستم برای خود یا دوستانش راه‌اندازی کند:

### گام ۱: ساخت مخزن اختصاصی
1. در بالای همین صفحه روی دکمه سبز رنگ **`Use this template`** (یا **`Fork`**) کلیک کنید.
2. یک نام دلخواه برای مخزن خود بگذارید (مثلاً `bale-telegram-viewer`) و نوع آن را حتماً **Public** انتخاب کنید.

### گام ۲: تنظیم دسترسی‌های GitHub Actions
1. در مخزن جدید خود، به تب **Settings** بروید.
2. از ستون سمت چپ وارد **Actions** > **General** شوید.
3. در انتهای صفحه، بخش **Workflow permissions** را پیدا کرده و گزینه **Read and write permissions** را انتخاب و **Save** کنید.

### گام ۳: اجرای اولین چرخه استخراج و فعال‌سازی Pages
1. به تب **Actions** در مخزن خود بروید و روی ورک‌فلو **Telegram Collector & Deploy** کلیک کنید.
2. دکمه **Run workflow** را بزنید تا اولین اجرای استخراج آغاز شود (پس از ۱ الی ۲ دقیقه سبز می‌شود و شاخه `gh-pages` ساخته خواهد شد).
3. مجدداً به **Settings** > **Pages** بروید:
   * مقدار **Source** را روی **Deploy from a branch** بگذارید.
   * شاخه را روی **`gh-pages`** و مسیر را روی **`/(root)`** تنظیم کرده و **Save** را بزنید.
   * آدرس سایت شما در بالای صفحه نمایش داده می‌شود:
     `https://<YOUR_USERNAME>.github.io/bale-telegram-viewer/`

### گام ۴: اتصال به ربات بله (بدون نیاز به سرور روشن)
1. در پیام‌رسان بله، وارد چت **`@BotFather`** شوید و با دستور `/newbot` یک ربات جدید بسازید و توکن آن را کپی کنید.
2. در کامپیوتر خود اسکریپت راه‌اندازی سریع را اجرا کنید:
   ```bash
   python scripts/quick_start.py
   ```
   (اسکریپت از شما توکن ربات بله و نام کاربری گیت‌هاب را می‌پرسد و دکمه منو را برای همیشه فعال می‌کند).

> 💡 **روش جایگزین بدون اسکریپت:** می‌توانید دستور تک‌خطی زیر را اجرا کنید:
> ```bash
> python bale/setup_bot.py --token "<YOUR_BALE_BOT_TOKEN>" --url "https://<YOUR_USERNAME>.github.io/bale-telegram-viewer/"
> ```

🎉 **تمام!** اکنون اپلیکیشن بله را باز کرده و وارد صفحه ربات خود شوید؛ دکمه منو در کنار کادر چت فعال شده و مینی‌اپ بدون فیلترشکن باز می‌شود.

## ⚙️ شخصی‌سازی کانال‌های پیش‌فرض

برای تغییر، افزودن یا حذف کانال‌های پیش‌فرض، فایل [`config/channels.json`](config/channels.json) را در مخزن خود ویرایش کنید:

```json
{
  "channels": [
    {
      "id": "durov",
      "title": "Pavel Durov",
      "enabled": true,
      "description": "پست‌های رسمی پاول دورف"
    },
    {
      "id": "zoomit",
      "title": "زومیت",
      "enabled": true,
      "description": "اخبار فناوری و گجت‌ها"
    }
  ]
}
```
به محض ذخیره فایل در شاخه `main`، اکشن گیت‌هاب به طور خودکار اجرا شده و پست‌های کانال‌های جدید را ظرف چند ثانیه دریافت می‌کند.

## 📁 ساختار پوشه‌بندی مخزن

```text
├── .github/workflows/
│   ├── collector.yml      # چرخه کرون خودکار (هر ۱۰ دقیقه)، کشینگ و دیپلوی
│   └── security.yml       # اسکن خودکار عدم نشت رمزها (gitleaks)
├── collector/
│   ├── main.py            # جمع‌آوری‌کننده، ادغام پیام‌ها و فیلتر پنجره لغزان
│   ├── parser.py          # استخراج متادیتا و پیام‌ها از پیش‌نمایش وب تلگرام
│   ├── media.py           # فشرده‌سازی عکس‌ها به WebP و صوت با FFmpeg
│   └── requirements.txt   # وابستگی‌های پایتون (requests, bs4, Pillow)
├── web/
│   ├── index.html         # چارچوب مینی‌اپ با SDK رسمی بله
│   ├── app.js             # منطق برنامه، اسکرول هوشمند، فالبک‌ها و تم
│   └── style.css          # استایل‌های مدرن تلگرامی سازگار با تم بله
├── bale/
│   ├── setup_bot.py       # تنظیم یک‌باره دکمه Menu Button ربات
│   └── run_bot.py         # اسکریپت اختیاری پاسخ به /start با دکمه شیشه‌ای
├── scripts/
│   └── quick_start.py     # دستیار تعاملی اتصال مینی‌اپ به ربات بله
├── config/
│   └── channels.json      # فهرست کانال‌های پیش‌فرض
├── docs/                  # مستندات تکمیلی معماری و راهنما
├── LICENSE                # مجوز منبع‌باز MIT
└── README.md
```

## 🛡️ امنیت و حریم خصوصی

* **کلاینت عمومی:** هیچ توکن یا کلیدی در فایل‌های کلاینت فرانت‌اند (`web/`) وجود ندارد. فرانت‌اند فقط فایل‌های JSON استاتیک و تصاویر را از شاخه `gh-pages` می‌خواند.
* **اعتبارسنجی ورودی‌ها:** ورودی‌های دیسپچ و ایشوها توسط Regex سخت‌گیرانه بررسی می‌شوند تا از هرگونه تزریق دستور یا حمله جلوگیری شود.
* **بدون ردگیری:** هیچ سرور واسط یا پایگاه داده‌ای برای رصد فعالیت کاربران وجود ندارد.
